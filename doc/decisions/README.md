# Architecture decisions

Use an ADR when an Open UI Kit decision is expensive to reverse, including public API philosophy,
dependency boundaries, Material/Cupertino isolation, token semantics, accessibility contracts,
supported SDK floors, release architecture, or a deliberate deviation from an established rule.

Copy `0000-template.md`, use the next four-digit number, and link the decision to its Architecture
decision issue and implementation pull requests. Valid statuses are `Proposed`, `Accepted`,
`Superseded by ADR NNNN`, and `Rejected`.
