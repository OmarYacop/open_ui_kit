# Security policy

Do not report suspected vulnerabilities in public issues or pull requests. Use GitHub's
[private vulnerability reporting](https://github.com/OmarYacop/open_ui_kit/security/advisories/new)
for package supply-chain, unsafe rendering, input handling, platform boundary, dependency, and
release-pipeline vulnerabilities.

Include a concise impact statement, affected versions and platforms, reproduction details, and a
suggested remediation when available. Never include real application credentials, personal data,
or proprietary host-application code. The maintainer will validate the report, coordinate a fix,
and disclose it after affected users can upgrade safely.
